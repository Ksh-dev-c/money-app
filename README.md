# Python家計簿アプリ

## 概要
Pythonで作成したCLI（コマンドライン）型の家計簿アプリです。

収入・支出の記録を追加し、月ごとの一覧表示や合計金額の確認ができます。
データはJSONファイルに保存されるため、アプリ終了後も記録が保持されます。

---

## 使用技術
- Python
- JSON

---

## 主な機能
- 収入追加
- 支出追加
- 月別一覧表示
- 月別合計表示
- 記録削除
- JSON保存

---

## 実行方法

```bash
python main.py
```

---

## データ保存形式

```json
[
  [2026, "05-18", "食費", -500],
  [2026, "05-18", "給料", 200000]
]
```
